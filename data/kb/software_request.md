# Requesting and Installing Software

## Approved software catalog
Many common tools are pre-approved and can be installed in a few clicks without a ticket:
- **Windows**: Open **Software Center** and choose the app from the Applications tab.
- **macOS**: Open the **Self Service** app and click Install next to the app.

The catalog includes browsers, PDF readers, compression tools, developer tools such as code editors and Git, and collaboration apps.

## Requesting software that is not in the catalog
1. Raise a request in the self-service portal under **Software > New Software Request**.
2. Include the software name, version, vendor website, and business reason.
3. Your manager approves the request first.
4. The security team reviews the software for risk. Free tools are usually reviewed within 2 business days.
5. If a paid license is needed, Procurement handles the purchase, which can take up to 10 business days.

Once approved, the software is added to Software Center or Self Service for you to install.

## Admin rights
Standard users do not have local administrator rights. Developers who regularly need admin rights can request **temporary elevation** through the self-service portal under **Access > Admin Elevation**. Elevation lasts 4 hours and every session is logged.

## Unapproved software
Installing software from unofficial sources, cracked software, or unlicensed copies is strictly prohibited. Browser extensions must also come from the approved list. Unapproved software found during security scans is removed automatically.
